# SKELAR — правила і еталони складних слайдів

Джерело правди для дизайн-систем у Клод Дизайні: правила верстки,
еталонні слайди, вбудовувані асети і виміри. Репозиторій публічний
навмисне — Клод Дизайн читає файли через raw-посилання без авторизації;
тому сюди не потрапляє жодна внутрішня цифра (ТЗ і згенеровані деки
живуть поза репо).

Версія правил стоїть у заголовках `rules.md`, `CLAUDE.md`, `types.md`
і завжди однакова в усіх трьох. Кожна змістовна зміна піднімає версію —
без цього sync у Клод Дизайні її не помітить.

## Файли

| Файл | Що це |
|---|---|
| `rules.md` | повна версія правил: механізми, шкали, заборони, історії дефектів |
| `CLAUDE.md` | операційний мінімум для кожного чату + протокол sync |
| `types.md` | закритий перелік типів слайдів, ємності, таблиця рішень |
| `rules-delta.md` | те, чого немає в основному брендбуку (палітра, статуси) |
| `reference.html` | еталон слайдів із даними: таблиці, KPI, рейтинги, графік |
| `reference-basic.html` | еталон базових типів: обкладинка, перебивки, адженда, текстові |
| `check.js` | вимір одного дека в консолі браузера: PASS/FAIL по кожному слайду |
| `audit.js` | `node audit.js deck.html --out DIR` — check.js + типи + асети + PNG кожного слайда (Chrome: env `CHROME` або стандартні шляхи) |
| `content-diff.py` | `python3 content-diff.py ТЗ deck.html` — кожен пункт ТЗ проти тексту дека; бандли рендерить сам |
| `deck-check.js` | прототип сторожа всередині дека — не активований, див. BACKLOG |
| `content/` | знаки SKELAR і embed-файли: фони `bg-embed-0…5.html`, фото `photo-embed-1…5.html`. Бінарні JPG поруч — джерело для людей, генерація бере лише embed |
| `ref1–5.png` | знімки актуального еталона `reference.html` — для звірки очима |
| `_cov.html` | проміжний еталон базових типів зі значень Figma (історичний) |
| `BACKLOG.md` | відкладене свідомо, з причинами |

## Дисципліна

«Готово» — це числа з `audit.js` і `content-diff.py`, не враження.
Кожне правило має вимір; перевірку, яка не вміє падати, ламають навмисне.
Дефекти найчастіше живуть в еталоні — його перевіряють перед правкою дека.
