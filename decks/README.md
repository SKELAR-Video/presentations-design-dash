# decks/ — архів деків (облік тут більше не живе)

**Кількість деків рахується автоматично**, з `v66`. Клод Дизайн за протоколом
читає правила перед кожним деком — тепер за адресою
`https://presentations-design.vercel.app/api/rules/<файл>`, яка віддає той самий
файл і пише рядок у вкладку «Клод Дизайн» таблиці використання. Жодної дії від
людини.

Чому так: Клод Дизайн не має права писати нікуди, тому єдине, що можна
порахувати, — його власне читання. Попередній облік просив людину перенести
рядок-слід із нотаток дека в журнал руками; за два місяці не перенесли жодного
разу при десятках реальних деків. Облік, який тримається на тому, що хтось не
забуде, — це не облік.

Рядок-слід у нотатках першого слайда лишається: по будь-якому деку видно, на
якій версії правил він зроблений.

Сюди можна складати фінальні файли, якщо потрібен архів; `stats.py` і
`JOURNAL.md` лишаються для ручних записів про деки, зроблені до `v66`.
