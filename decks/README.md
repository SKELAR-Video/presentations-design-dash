# decks/ — сюди складаються готові деки для статистики

Клади сюди фінальні файли деків (`.html` або `.pptx`) — можна в підпапках
по тімах чи місяцях, скрипт бачить усе дерево.

Статистика НЕ збирається сама: Клод Дизайн не має права писати ні сюди, ні
куди-інде. Рахує `stats.py` за рядком-слідом у нотатках першого слайда
(`SKELAR deck · правила vNN · дата · тіма`) і переписує `STATS.md`.

Щоб оновити цифри — скажи Клоду в цьому репозиторії «онови статистику»:
він покладе нові файли, запустить скрипт і запушить `STATS.md`.
