Один рядок = один згенерований дек. Файли деків сюди класти не треба —
тільки рядок, який Клод Дизайн друкує разом із `ГОТОВО`. Додати його можна
просто в браузері: відкрити цей файл на GitHub → олівець → вставити рядок
знизу → Commit. `stats.py` рахує і журнал, і папку `decks/` разом.
